SKY AI FOREX PRO — ADMIN PANEL SETUP

1. Extract this ZIP on your phone.
2. Upload index.html, style.css, config.js and app.js to the root of the GitHub repository connected to your Cloudflare Pages project. Replace files with the same names.
3. Open Firebase Console > Project settings > General > Your apps. Select your Firebase Web app, choose the Config option, and copy the real values into config.js. Do not paste a service-account private key here.
4. In Firebase Authentication, enable Email/Password and create your admin login account.
5. In Firestore, create collection "admins". Create a document whose document ID is exactly the admin user's Firebase Authentication UID. Add boolean field active = true.
6. Publish firestore.rules only after reviewing the warning below.
7. Wait for Cloudflare Pages to redeploy, then open your Pages website.

IMPORTANT FIRESTORE RULES WARNING
These sample rules are intentionally read-only. They allow approved admins to read users, devices and activity, and deny all client writes and all other collections. Publishing them as a full replacement can break an app that needs to write to Firestore or uses other collections. If your Android app already writes data, do not replace its current rules yet; combine the permissions carefully.

The admin panel does not create users/devices/activity records. Those collections must be written by your app or backend. Collection fields shown are examples: users email/status; devices userId/platform; activity type/userId/createdAt.

Firebase Web config is client-side configuration. Never put Firebase service-account JSON, private keys, broker passwords, or API secrets in these files.
